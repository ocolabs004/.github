# OcoLabs

> 만들 수 있는 것이 아니라, 운영할 수 있는 것을 만듭니다.

오코랩스는 거창한 기술보다 현실적인 문제 해결을 우선하는 개발팀입니다.  
MVP부터 실제 운영 단계까지 이어지는 실전형 서비스를 만듭니다.

---

## 🚀 What We Do

- 아이디어를 실제 서비스로 만드는 MVP 개발  
- 내부 운영 도구와 백오피스 구축  
- 기존 서비스 개선 및 유지보수  
- 외주 개발 및 협업 프로젝트

만들고 끝나는 프로젝트가 아니라,  
실제로 사용되고 성장하는 제품을 목표로 합니다.

---

## 🧭 Our Philosophy

**실용 우선**  
최신 유행보다 현재 문제를 가장 안정적으로 해결하는 방법을 선택합니다.

**작게 시작, 빠른 검증**  
완벽한 설계보다 동작하는 결과물을 먼저 만듭니다.

**읽히는 코드**  
복잡한 구조보다 명확하고 유지보수 가능한 코드를 지향합니다.

**지속 가능한 개발**  
무리한 일정 대신 꾸준히 개선되는 속도를 지킵니다.

---

## 🛠 How We Work

- 모든 변경은 Pull Request 기반  
- 코드 리뷰 중심 협업  
- 규칙은 최소한으로, 필요할 때만 강화  
- 투명하고 단순한 의사결정

---

## 📦 Repository Policy

- 프로젝트별 독립 저장소 운영  
- main 브랜치 직접 push 금지  
- CI 통과 후 머지  
- 최소 1인 리뷰 권장

절차를 위한 규칙이 아니라,  
문제를 줄이기 위한 규칙을 만듭니다.

---

## 🤝 Collaboration

좋은 아이디어와 재미있는 프로젝트를 환영합니다.

- 명확한 목적의 제안  
- 최소 단위의 PR  
- 이유가 설명된 커밋 메시지  
- 재현 가능한 이슈 리포트

이 네 가지만 있으면 충분합니다.
